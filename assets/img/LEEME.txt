Recomendaciones
---------------
- Formato vertical (aprox. 800 x 1000 px) para las de galería.
- Formato horizontal (aprox. 800 x 600 px) para consulado.jpg.
- Guárdalas comprimidas: menos de 300 KB cada una para que la
  página cargue rápido en el celular.
- Si cambias un nombre de archivo, cámbialo también en el HTML
  de las páginas donde aparece.
